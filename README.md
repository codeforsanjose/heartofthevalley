# Heart of the Valley

## How to Run the Project

1. **Clone the Repository**:
   ```bash
   git clone
   ```
2. **Navigate to the Project Directory**:
   ```bash
   cd heartofthevalley
   ```
3. **Run in Docker**:

   ```bash
   docker compose watch
   ```

4. **Open in Browser**:
   - Navigate to `http://localhost:3000` to view the application.
